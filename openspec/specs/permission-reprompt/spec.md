## ADDED Requirements

### Requirement: 多次权限请求独立提示

系统 SHALL 在 Agent 运行期间持续监听权限请求通道。当用户选择「仅允许一次」后，后续工具调用若再次触发权限检查，系统 MUST 重新渲染权限提示弹窗并等待用户响应，而非永久阻塞。

#### Scenario: 连续两次选择"仅允许一次"

- **WHEN** Agent 连续调用两个需要权限提升的工具
- **AND** 用户对第一个工具选择"仅允许一次"（Y 键）
- **THEN** 第二个工具的权限请求应正常弹出提示
- **AND** 系统不挂死

#### Scenario: 拒绝后再次请求权限

- **WHEN** 用户拒绝了某个工具的权限请求（N 键）
- **AND** Agent 随后又调用了需要权限的工具
- **THEN** 新工具的权限请求应正常弹出提示
- **AND** 系统不挂死

#### Scenario: 永久允许后不同工具仍需权限

- **WHEN** 用户对 Bash 工具选择了"始终允许"（A 键）
- **AND** Agent 随后调用了 Write 工具（不同工具，也需要权限）
- **THEN** Write 工具的权限请求应正常弹出提示
- **AND** Bash 工具不再弹出权限提示
